How-to guide: for a project manager whose agent reports it is blocked or whose package has stopped moving.

# How to unblock an agent

This guide shows you how to clear a block in the fewest messages.

1. Write the block in one line: what it needs, from whom, and when the
   wait starts to cost.
2. Search the rules record, contracts and plan. If they answer it,
   reply with the answer and the entry id. Done.
3. If another role owns the answer, message both agents together with
   the exact question. Step out.
4. If the block is unfinished work, agree a stub against the contract
   so both sides can continue.
5. If it is sequencing or package boundaries, decide, record it in the
   plan, and tell both sides.
6. If the work needs a role that does not exist, see
   [How to staff a job no role covers](how-to-staff-a-job-no-role-covers.md).
7. If only the owner can decide, send one message: question, why now,
   options with consequences, your recommendation, and the default if
   they don't answer. Record their answer.
8. Update the package status when the block clears.

For disputes between agents and the escalation format in full, see the
[routing-and-unblocking reference](../reference/skills/routing-and-unblocking.md).
