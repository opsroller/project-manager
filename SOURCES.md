# Sources

Reference: the research behind this plugin, for anyone checking where its methods come from.

| Source | Informed |
|---|---|
| [The Kanban Guide (Kanban Guides, 2020.12)](https://kanbanguides.org/the-kanban-guide/2020.12) | Definition of workflow, WIP control, active management, flow metrics, SLE (`flow-and-risks`) |
| [Scrum Guide 2020 vs 2017 comparison (Scrum.org)](https://www.scrum.org/resources/blog/scrum-guide-2020-and-2017-side-side-comparison) | Accountabilities, commitments, "causing the removal of impediments" (explanation, `routing-and-unblocking`) |
| [Scrum Master accountable for delivery? (Scrum.org)](https://www.scrum.org/resources/blog/scrum-master-accountable-delivery) | Coordinator accountable for effectiveness, not doing the work (agent boundaries) |
| [Inside PMBOK 7: the 12 principles](https://projectmanagementcompass.substack.com/p/inside-pmbok-7-the-12-principles) | Tailoring, stakeholder engagement, value, risk principles (explanation, no invented process) |
| [PMBOK principles, domains and artifacts (MPUG)](https://mpug.com/pmbok-principles-performance-domains-and-artifacts-how-do-they-work-together) | Risk register and ongoing risk response (`flow-and-risks`) |
| [Work breakdown structure (Wikipedia, citing PMI)](https://en.wikipedia.org/wiki/Work_breakdown_structure) | 100% rule, mutually exclusive elements, outcomes not actions, sizing (`work-breakdown`) |
| [SFIA: Project management (PRMG)](https://sfia-online.org/en/skillcode/8/PRMG) | Definition of the job and levels 4-7 (explanation, career growth) |
| [O*NET: Project Management Specialists 13-1082.00](https://www.onetonline.org/link/summary/13-1082.00) | Core tasks and work activities (explanation) |
| [GOV.UK Design System team playbook: delivery manager roles](https://team-playbook.design-system.service.gov.uk/delivery-management/delivery-manager-roles-and-responsibilities) | Delivery manager duties: blockers, visibility, reporting, risk escalation |
| [UK Government digital and data framework: delivery manager](https://understand-digital-data-roles-skills.service.gov.uk/role/delivery-manager/) | Skills and levels from associate to head of delivery (explanation) |
| [GitLab: Technical Program Management job family](https://handbook.gitlab.com/job-families/engineering/technical-program-management/technical-program-management-ic) | TPM responsibilities and level expectations; dependencies, risks, status |
| [GitLab Handbook: Directly Responsible Individuals](https://handbook.gitlab.com/handbook/people-group/directly-responsible-individuals/) | One owner per thing; disagree and commit (`routing-and-unblocking`) |
| [Engineering ladders: Technical Program Manager](https://engladders.beyondpricing.com/TechnicalProgramManager.html) | Progression from adjusting to defining processes (explanation) |
| [Dropbox: Staff Technical Program Manager posting](https://jobs.accel.com/companies/dropbox/jobs/62539399-staff-technical-program-manager-engineering-productivity) | Influence without authority, metrics for program health, scalable process |
| [Google: Technical Program Manager posting](https://jobs.anitab.org/companies/google-24698/jobs/84881963-technical-program-manager-pdi) | Cross-functional coordination, risk mitigation, stakeholder communication |
| [Atlassian Team Playbook: DACI](https://www.atlassian.com/team-playbook/plays/daci) | Single approver, decision record fields (`standing-rules`, escalation format) |
| [Architecture decision records (Red Hat)](https://www.redhat.com/en/blog/architecture-decision-records) | Dated, superseded decision records (`standing-rules` record format) |
| [How to make great decisions async (Doist / Twist)](https://async.twist.com/how-to-make-decisions-asynchronously/) | Recommendation up front, one decider, record and share outcome (escalation format) |
| [Shape Up appendix (Basecamp)](https://basecamp.com/shapeup/4.0-appendix-01) | Appetite, independent scopes, hill charts, progress visible without asking |
| [RAG and BRAG status (Rebel's Guide to Project Management)](https://rebelsguidetopm.com/understanding-rag-in-project-management/) | Defined status criteria, path to green, honesty (`status-reporting`) |
| [Diataxis](https://diataxis.fr/) and the project's Diataxis guide | Docs layout of this plugin and the docs steps in every workflow |
